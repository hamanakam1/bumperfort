# Learning Path

Suggested order of study:

1. Read `precision_mod` (kinds are foundational)
2. Read `physics_mod` and run the tests (pure numerical thinking)
3. Read `ffi_mod` + `docs/ffi-explained.md` (the hardest & most valuable concept)
4. Look at the Python binding and try calling it
5. Read `coarray_mod` and `telemetry_mod` (parallel mental model)
6. Read the strategy & roadmap docs to see the long game
